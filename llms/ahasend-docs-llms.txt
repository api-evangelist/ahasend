- [Get Webhook](https://ahasend.com/docs/api-reference/webhooks/get-webhook.md): Returns a specific webhook by ID. Access requires the global read role or a read role matching at least one associated domain.

- [List Routes](https://ahasend.com/docs/api-reference/routes/get-routes.md): Returns a list of routes for the account. A domain-scoped key must provide the matching `domain` query parameter; the global read role can list without that filter.
- [Update Route](https://ahasend.com/docs/api-reference/routes/update-route.md): Updates an existing route. A domain-scoped key must authorize the existing recipient domain and, when `recipient` changes, the new domain; `routes:write:all` satisfies both checks.
